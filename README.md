# Підтримка ветеранів

Минимальный фундамент на Accessible Astro Starter (MIT), upstream 6.0.1.
Перед работой читать PROJECT.md и STATUS.md.

```sh
npm ci
npm run dev
npm run build
npm run lint
npm audit
```

Локальный контент: src/content/pages/*.md. Схема: src/content.config.ts.
Без CMS, публичных форм, аналитики и deployment. Брендинг временный.
Noto Sans хранится локально; лицензия SIL OFL в public/fonts/OFL.txt.
